# Kampung Sayur Jum'at Barokah (Next.js + Tailwind)

## Struktur folder
- `src/app/page.js`      → halaman beranda (susunan komponen)
- `src/app/layout.js`    → judul situs, font, preview WhatsApp
- `src/components/`      → satu file = satu bagian halaman (Navbar, Hero, dst.)
- `src/data/dataSitus.js`→ semua teks/angka/rekening (EDIT DI SINI dulu)
- `public/foto/`         → taruh foto asli, lalu tulis path-nya di dataSitus.js
- `tailwind.config.js`   → warna & font

## Menjalankan di komputer
npm install
npm run dev     (buka http://localhost:3000)
